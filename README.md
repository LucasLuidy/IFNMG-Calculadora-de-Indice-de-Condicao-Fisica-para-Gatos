**Calculadora de Índice de Condição Física para Gatos em Linguagem Python**

📌 **Objetivo do Projeto**  
Desenvolvi este programa em Python para classificar gatos com base no índice PGCF (Índice de Gato com Base na Circunferência Torácica e Distância entre o Calcâneo e a Patela). Ele calcula o PGCF de cada gato e os categoriza em três grupos: abaixo do peso, peso ideal e acima do peso, além de calcular a média de PGCF de cada categoria.  

🛠 **Tecnologias Utilizadas**   
- Linguagem Python
- Funções de cálculo e controle de fluxo (loops, condições) 

📚 **O que aprendi/desenvolvi**  
- Implementação de funções matemáticas para cálculos biométricos  
- Uso de loops e condicionais para categorização dos dados  
- Aplicação de médias estatísticas para análise dos resultados  
- Melhoria na experiência do usuário, evitando entradas inválidas
